# Sistema de Atendimento

Sistema de gerenciamento de filas e guichês desenvolvido em C# (Windows Forms) utilizando os princípios de Orientação a Objetos.

## Estrutura do Projeto

- **Models**: Contém as classes de domínio (`Senha`, `Senhas`, `Guiche`, `Guiches`).
- **Views/Forms**: A interface gráfica construída com Windows Forms (`Form1`).

## Como Executar

1. Extraia a pasta do projeto.
2. Abra a pasta no Visual Studio ou VS Code.
3. Certifique-se de ter o .NET SDK instalado.
4. Restaure os pacotes e execute o projeto (Pressione F5 no Visual Studio ou execute `dotnet run` no terminal).
